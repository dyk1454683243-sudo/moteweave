# Runbook Index

Use these runbooks for repeatable local checks and import workflows.

## Character Pack

- `character-pack-cli.md`: stable CLI commands for process, generate, benchmark, and multi-resolution artifact checks.
- `character-pack-benchmark.md`: local compatibility benchmark and optional Godot probe.
- `processed-sample-benchmark.md`: summarizes already-generated local debug reports without provider quota.

## Live Generation

- `openrouter-gemini-smoke.md`: single live generation smoke flow.
- `openrouter-real-benchmark.md`: live provider benchmark gate.
- `t2i-provider-readiness.md`: provider route matrix, static prompt audit, and next-window T2I live gate order.
- `two-point-five-d-material-source-benchmark.md`: 2.5D material-source dry-run, human live-run, and provider-free review handoff.

## Engine Import

- `godot-npc-plugin-import.md`: Godot NPC plugin import workflow.
- `rpgmaker-import.md`: RPGMaker compatibility import workflow.
- `ocad-plugin-import.md`: OCAD compatibility import workflow.

## Editor Workspace

- `targeted-frame-repair-v1.md`: deterministic single-frame mask/Plan,
  one-call/recovery, sealed acceptance, Workbench UI, verification evidence,
  and live-quality rollout boundary.

- `release-closeout-2026-06-23.md`: release closeout candidate covering the
  merged Editor Workspace, Motion Source, scene/2.5D, and quality surfaces.
- `editor-workspace-v0-closeout.md`: final v0 merge route, acceptance checks,
  review note, and next-round handoff pointer.
- `editor-workspace-engine-handoff-v1.md`: static and manual review checklist
  for neutral, Godot, LDtk, and consumer evidence handoff files.
- `editor-workspace-consumer-evidence-review.md`: stacked PR target, review
  checklist, verification evidence, and merge route for the consumer evidence
  layer.
