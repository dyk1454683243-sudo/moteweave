# v0.4 Master Plan

**Date:** 2026-06-05
**Status:** Active

## Goal

Start the scene/tile generation direction without weakening the existing character-pack pipeline. v0.4 begins by paying the pixel style pipeline debt needed before reliable tile generation.

## Direction

v0.4 selects Scene / Tile Generation as the product direction.

The execution order is intentionally front-loaded:

1. Phase 0: pixel style pipeline debt.
2. Phase 1: tile structure and seam-safe tile profiles.
3. Phase 2: arrangement and export.
4. Phase 3: character plus scene pack integration.

  - `downsampleNearest()`
  - report-only style drift metrics
- Keep the implementation original and dependency-free unless a later decision approves a dependency.

- Integrate into the existing character-pack process path as report-only or opt-in.
- Do not change `normalized_sheet.png`, exports, Row GIFs, or ZIP contents by default.

Initial implementation unit:

## Completion Rules

- Commit each coherent phase or sub-phase after focused verification.
- Do not claim tile-generation readiness until Phase 0 metrics are present and covered by tests.
- Keep live provider gates optional unless the phase explicitly changes generation prompts or provider behavior.
